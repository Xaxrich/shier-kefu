# 硬件设备申请流程

## 适用范围

本文档适用于员工因工作需要申请新硬件设备，包括显示器、键盘、鼠标、耳机、笔记本电脑、扩展坞等。

---

## 可申请设备清单

| 设备类型 | 标准配置 | 审批级别 |
|---------|---------|---------|
| 鼠标、键盘 | 公司统一采购型号 | 部门主管审批 |
| 耳机（有线） | 标准办公耳机 | 部门主管审批 |
| 显示器 | 24 寸 1080P / 27 寸 2K | 部门主管审批 |
| 扩展坞/转接器 | USB-C 多口扩展坞 | 部门主管审批 |
| 笔记本电脑 | 按岗位标准配置 | 部门总监 + IT 审批 |
| 特殊设备（绘图板等） | 按需评估 | 部门总监 + IT + 采购审批 |

---

## 申请流程

### 第一步：提交申请
1. 登录 OA → IT 服务 → 设备申请
2. 填写以下信息：
   - 申请设备名称和数量
   - 用途说明（为什么需要）
   - 是否替换旧设备（如是，提供旧设备资产编号）
3. 提交后自动进入审批流

### 第二步：审批流程
- 普通外设（鼠标、键盘、耳机）：部门主管审批 → IT 确认库存 → 发放
- 显示器、扩展坞：部门主管审批 → IT 确认库存 → 发放
- 笔记本电脑：部门主管 → 部门总监 → IT 评估 → 采购（如无库存）→ 发放
- 特殊设备：部门主管 → 部门总监 → IT 评估 → 采购审批 → 采购 → 发放

### 第三步：领取设备
- 有库存：审批通过后 1 个工作日内 IT 配送到工位
- 需采购：审批通过后 5-10 个工作日到货

---

## 换新标准

| 设备类型 | 使用年限达到可换新 |
|---------|------------------|
| 笔记本电脑 | 3 年 |
| 台式机 | 4 年 |
| 显示器 | 5 年 |
| 键盘/鼠标 | 损坏即可更换 |

---

## 旧设备回收

- 换新时旧设备须交还 IT 部门
- IT 会清除设备数据后进行资产回收
- 不得私自处置公司资产设备

---

## 常见问题

**Q：入职新员工怎么领设备？**
A：由 HR 在入职流程中自动触发设备申请，IT 会在入职当天准备好设备。

**Q：离职时设备怎么处理？**
A：离职交接时须归还所有公司设备，由 IT 确认后办理资产注销。

**Q：可以自带设备办公吗？**
A：需经 IT 安全评估，个人设备须安装公司安全软件并遵守安全策略。
