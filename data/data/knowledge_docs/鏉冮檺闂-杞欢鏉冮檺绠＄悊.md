# 软件权限管理指南

## 适用范围

本文档适用于员工遇到软件访问权限相关问题，包括无法登录系统、账号被锁定、权限不足等。

---

## OA 系统无法登录

### 常见原因及解决方案

#### 密码错误
1. 确认是否使用最新密码（密码每 90 天需修改一次）
2. 检查大小写锁定键（Caps Lock）是否误开
3. 点击登录页面的"忘记密码" → 通过绑定手机号重置
4. 如未绑定手机号，联系 IT 重置密码

#### 账号被锁定
- 连续 5 次密码错误会触发锁定
- 锁定时间：30 分钟自动解锁
- 急需使用：联系 IT 手动解锁（内线 8888）

#### 账号被禁用
- 可能原因：长期未登录（超过 90 天）、离职流程触发、安全策略
- 处理方式：联系 IT 核实账号状态

## 邮箱（Outlook / Exchange）权限问题

### 无法收发邮件
1. 检查网络连接是否正常
2. 确认 Outlook 右下角的连接状态（应显示"已连接"）
3. 尝试 Outlook Web 版（网页邮箱）登录测试
4. 如果 Web 版可用但客户端不行，可能是 Outlook 配置问题，参考《软件故障排查指南》

### 共享邮箱无权限
1. 确认是否已被添加为共享邮箱成员
2. 如未添加，由邮箱管理员在 Exchange 管理后台添加
3. 添加后需重启 Outlook 生效

### 邮件组无法发送
1. 确认邮件组是否设置了发送限制
2. 联系邮件组管理员添加发送权限

## 业务系统权限申请

### 标准流程
1. OA → IT 服务 → 系统权限申请
2. 填写：系统名称、需要的权限级别、申请原因
3. 审批流：部门主管 → 系统管理员 → 开通
4. 常见系统权限开通时间：1-2 个工作日

### 常见业务系统
| 系统名称 | 权限管理员 | 申请方式 |
|---------|-----------|---------|
| OA 系统 | IT 部门 | OA 工单 |
| CRM 系统 | 销售运营部 | OA 工单 + 部门审批 |
| ERP 系统 | 财务部 | OA 工单 + 多级审批 |
| HR 系统 | 人力资源部 | OA 工单 |
| 知识库 | IT 部门 | OA 工单 |

## Windows 凭据问题

### 清理 Windows 凭据管理器
某些情况下旧的缓存凭据会导致登录失败：
1. 控制面板 → 用户账户 → 凭据管理器
2. 找到对应系统的 Windows 凭据
3. 展开 → 删除
4. 重新打开软件，输入最新的用户名和密码

---

## 许可证 / License 问题

### Office 提示"未授权"
1. 文件 → 账户 → 检查是否使用公司邮箱登录
2. 退出当前账号 → 重新登录公司邮箱
3. 仍提示未授权：联系 IT 检查 License 分配

### 其他软件许可证过期
- 联系 IT 登记，由 IT 统一管理续费
- 不要自行在网上寻找破解版或序列号
