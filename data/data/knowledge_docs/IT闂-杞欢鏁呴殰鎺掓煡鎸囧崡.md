# 软件故障排查指南

## 适用范围

本文档适用于员工日常使用的办公软件出现故障（打不开、闪退、崩溃、报错、无响应等）的自助排查。

---

## Outlook 邮箱打不开 / 崩溃

### 排查步骤
1. 打开任务管理器（Ctrl+Shift+Esc），找到 Outlook 进程，右键 → 结束任务
2. 以安全模式启动 Outlook：Win+R → 输入 `outlook.exe /safe` → 回车
3. 如果安全模式能打开，说明是插件导致的问题：
   - 文件 → 选项 → 加载项 → 管理 COM 加载项 → 禁用所有 → 逐个启用排查
4. 清理 Outlook 缓存：
   - 关闭 Outlook
   - Win+R → 输入 `%localappdata%\Microsoft\Outlook` → 删除 .ost 文件
   - 重新打开 Outlook，会自动重建缓存
5. 仍无效请提交工单

### 常见错误
- "无法启动 Microsoft Outlook。无法打开 Outlook 窗口"：删除导航窗格配置文件，Win+R → `outlook.exe /resetnavpane`
- "发送/接收报错"：检查网络连接，确认 Exchange 服务器可访问

## Office 系列崩溃（Word / Excel / PowerPoint）

### 排查步骤
1. 修复 Office：控制面板 → 程序 → Microsoft Office → 更改 → 联机修复
2. 修复完成后重启电脑
3. 如果仍有问题，检查是否只有特定文件崩溃：
   - 打开其他文件正常 → 原文件可能已损坏，尝试 Word → 打开 → 浏览 → 选文件 → 打开旁的下拉箭头 → "打开并修复"
   - 所有文件都崩溃 → Office 安装损坏，需 IT 重装
4. 提交工单时附上错误提示截图

### Excel 常见问题
- 打开大文件卡死：文件 → 选项 → 公式 → 取消勾选"自动重算"
- 宏报错：文件 → 选项 → 信任中心 → 宏设置 → 启用所有宏（仅限受信任文件）

## 软件无响应 / 卡死

### 通用排查步骤
1. 等待 2-3 分钟，看标题栏是否显示"未响应"
2. 打开任务管理器 → 找到对应软件 → 结束任务
3. 重新打开软件
4. 如果频繁卡死：
   - 检查内存使用率（任务管理器 → 性能标签）
   - 内存使用超过 85%：关闭不用的软件，重启电脑
   - 硬盘使用率 100%：可能是 Windows Update 或杀毒软件在后台运行，等待完成
5. 长期频繁卡死请提交工单

## 软件报错

### 排查步骤
1. 截图或记录完整的错误信息
2. 搜索错误代码的含义（可在智能客服中直接输入错误代码）
3. 常见错误类型：
   - **缺少 DLL 文件**：安装 Visual C++ 运行时库
   - **权限不足**：右键 → 以管理员身份运行
   - **版本不兼容**：检查软件版本和系统版本的兼容性
4. 提交工单时务必附上错误截图

## 蓝屏错误（BSOD）

### 常见蓝屏错误码及含义
| 错误码 | 可能原因 |
|-------|---------|
| IRQL_NOT_LESS_OR_EQUAL | 驱动程序冲突 |
| CRITICAL_PROCESS_DIED | 关键系统进程崩溃 |
| PAGE_FAULT_IN_NONPAGED_AREA | 内存故障或驱动问题 |
| KERNEL_DATA_INPAGE_ERROR | 硬盘故障 |
| SYSTEM_SERVICE_EXCEPTION | 系统服务异常 |

### 处理方式
1. 记录错误码，强制重启电脑
2. 如果能进系统，打开事件查看器检查系统日志
3. 偶发一次（一个月内不超过 1 次）：观察即可
4. 频发（一周超过 2 次）：提交工单，附上错误码
