# 硬件故障排查指南

## 适用范围

本文档适用于员工日常遇到的硬件设备故障自助排查，包括显示器、键盘、鼠标、耳机、主机等外设和终端设备。

---

## 显示器不亮 / 黑屏

### 常见原因
- 电源线或信号线松动
- 信号源选择错误
- 显卡驱动异常
- 显示器本身损坏

### 排查步骤
1. 检查显示器电源指示灯是否亮起，如果不亮，检查电源线是否插紧
2. 检查信号线（HDMI/DP/VGA）两端是否插紧，尝试重新拔插
3. 按显示器上的"信号源切换"按钮，确认选择了正确的输入源
4. 如果使用扩展坞/转接器，尝试直连测试
5. 将显示器连接到其他电脑测试，判断是显示器问题还是主机问题
6. 以上步骤均无效，请提交维修工单

---

## 键盘无响应

### 常见原因
- USB 接口松动或损坏
- 无线键盘电池耗尽
- 驱动程序异常

### 排查步骤
1. 有线键盘：拔出 USB 接口，换一个 USB 口重新插入
2. 无线键盘：检查电池电量，更换电池或充电；检查 USB 接收器是否插好
3. 蓝牙键盘：进入系统蓝牙设置，删除配对后重新连接
4. 打开设备管理器，检查键盘设备是否有黄色感叹号，有则右键更新驱动
5. 重启电脑测试
6. 仍无效请提交维修工单

---

## 鼠标失灵 / 光标漂移

### 排查步骤
1. 有线鼠标：换一个 USB 口测试
2. 无线鼠标：检查电池和接收器
3. 清洁鼠标底部传感器（用干布擦拭）
4. 检查鼠标垫表面是否反光或过于光滑（光电鼠标在玻璃面上可能失灵）
5. 打开设备管理器检查驱动状态
6. 仍无效请提交维修工单

---

## 电脑无法开机

### 排查步骤
1. 检查电源线是否插好，插座是否有电（试试其他电器）
2. 笔记本电脑：拔掉电源适配器，长按电源键 15 秒放电，重新接上电源开机
3. 台式机：检查机箱后方电源开关是否打开（I = 开，O = 关）
4. 听是否有风扇转动声或硬盘启动声
5. 如果有蜂鸣声（滴滴响），记录响声次数，联系 IT 报修
6. 无任何反应请提交维修工单

---

## 电脑死机 / 蓝屏

### 排查步骤
1. 蓝屏：记录屏幕上的错误代码（如 IRQL_NOT_LESS_OR_EQUAL）
2. 长按电源键 10 秒强制关机，等待 30 秒后重新开机
3. 如果能进入系统，打开"事件查看器"（Win+R → eventvwr）查看系统日志
4. 检查最近是否安装过新软件或驱动，尝试卸载
5. 运行 Windows 内存诊断工具（Win+R → mdsched.exe）
6. 频繁蓝屏（一周超过 2 次）请提交维修工单，附上错误代码

---

## 耳机 / 音响没声音

### 排查步骤
1. 检查系统音量是否静音（点击任务栏音量图标）
2. 右键音量图标 → 打开声音设置 → 确认输出设备选择正确
3. 检查耳机/音响的物理连接（3.5mm 插头或 USB）
4. 蓝牙耳机：确认已配对连接，且音频输出指向蓝牙设备
5. 打开设备管理器 → 声音设备 → 检查是否有黄色感叹号
6. 仍无效请提交维修工单
