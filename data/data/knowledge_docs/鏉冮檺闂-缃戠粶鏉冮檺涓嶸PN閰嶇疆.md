# 网络权限与 VPN 配置指南

## 适用范围

本文档适用于员工在使用公司网络、VPN 远程办公、WiFi 连接等场景中遇到的权限和配置问题。

---

## VPN 无法连接

### 排查步骤

#### 第一步：检查网络基础
1. 确认本地网络正常（能打开百度等外网页面）
2. 如果外网也不通，先解决网络问题

#### 第二步：检查 VPN 客户端
1. 确认 VPN 客户端版本是否为最新（公司当前标准版本：v4.2.x）
2. 旧版本可能存在兼容性问题，从 OA → IT 服务 → 软件下载 获取最新版
3. 卸载旧版 → 重启 → 安装新版

#### 第三步：检查账号和认证
1. 确认 VPN 账号和密码正确（与 OA 账号相同）
2. 检查 MFA（多因素认证）：
   - 手机验证码是否能正常接收
   - 动态令牌 APP 时间是否准确（手机时间需与网络同步）
3. 账号被锁定：连续 5 次失败会锁定 30 分钟

#### 第四步：检查配置文件
1. VPN 客户端 → 设置 → 导入配置文件
2. 配置文件获取：OA → IT 服务 → VPN 配置 → 下载最新配置
3. 导入新配置后重新连接

#### 第五步：仍然失败
1. 收集以下信息提交工单：
   - VPN 客户端版本号
   - 错误提示截图
   - 连接日志（VPN 客户端 → 帮助 → 导出日志）
   - 本地网络环境（家庭 WiFi / 手机热点 / 酒店网络）

### 常见 VPN 错误
| 错误提示 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 连接超时 | 网络不稳定或防火墙拦截 | 换网络环境或手机热点测试 |
| 认证失败 | 密码错误或账号锁定 | 重置密码或等待 30 分钟 |
| 证书过期 | VPN 证书到期 | 下载最新配置文件 |
| 服务器不可达 | VPN 服务器维护 | 查看 IT 通知或联系 IT |

## 公司 WiFi 无法连接

### 公司 WiFi 网络列表
| SSID | 用途 | 认证方式 |
|------|------|---------|
| Corp-Work | 办公网络 | 域账号认证 |
| Corp-Guest | 访客网络 | 前台获取密码 |
| Corp-IoT | 设备专用 | IT 配置 |

### Corp-Work 连接步骤
1. 选择 Corp-Work 网络
2. 认证方式：EAP-PEAP
3. 用户名：OA 账号（不含 @company.com）
4. 密码：OA 密码
5. 首次连接可能提示证书验证 → 点击"信任"

### 连不上 Corp-Work
1. 忘记此网络 → 重新连接 → 重新输入账号密码
2. 检查 OA 密码是否过期（密码 90 天有效期）
3. 检查是否被 MAC 地址绑定限制（新设备需 IT 添加白名单）
4. 仍连不上提交工单

## 远程桌面连接

### 连接方式
1. Win+R → `mstsc` → 输入目标电脑 IP 或主机名
2. 使用域账号登录

### 远程桌面连不上
1. 确认目标电脑已开机且联网
2. 确认已开启远程桌面：目标电脑 → 设置 → 远程桌面 → 启用
3. 检查防火墙是否放行 3389 端口
4. VPN 连接状态下才能访问公司内网设备
5. 权限问题：联系 IT 将你的账号添加到目标电脑的远程桌面用户组

## 网络访问受限

### 部分网站无法访问
- 公司防火墙会拦截与工作无关的网站
- 如因工作需要访问被拦截的网站：OA → IT 服务 → 网站白名单申请

### 内网资源无法访问
1. 确认是否连接了公司网络（办公室 WiFi 或 VPN）
2. 尝试 ping 目标地址确认网络可达性
3. 提交工单，附上目标地址和错误信息
