# 硬件权限管理指南

## 适用范围

本文档适用于员工在使用硬件设备时遇到的权限限制问题，包括 USB 设备被禁用、打印机无权限、外接设备无法识别等。

---

## USB 设备被禁用

### 公司安全策略说明
为防止数据泄露，公司对 USB 存储设备实施安全管控：
- **默认禁止**：U 盘、移动硬盘等 USB 存储设备
- **默认允许**：USB 键盘、鼠标、耳机等非存储外设

### U 盘 / 移动硬盘无法使用
1. 确认设备插入后是否有提示（可能被安全软件拦截）
2. 这是正常的安全策略，非设备故障
3. 如因工作需要使用 USB 存储设备：
   - OA → IT 服务 → USB 权限申请
   - 填写：使用原因、数据类型、使用期限
   - 审批：部门主管 → IT 安全 → 开通临时权限
   - 临时权限有效期：通常 1-7 天

### 替代方案
- 文件传输建议使用公司网盘或内网文件共享
- 跨设备传输可使用企业微信文件传输助手

## 打印机无权限

### 网络打印机无法打印
1. 确认打印机是否在线（打印机面板显示就绪状态）
2. 检查电脑是否连接了正确的打印机：
   - 设置 → 蓝牙和设备 → 打印机 → 确认默认打印机
3. 删除打印机后重新添加：
   - 设置 → 打印机 → 删除设备 → 添加打印机 → 搜索网络打印机
4. 打印机驱动问题：联系 IT 重装打印机驱动

### 彩色打印权限
- 部分打印机限制彩色打印权限
- 需要彩色打印：OA → IT 服务 → 打印权限申请
- 部门主管审批即可

### 楼层打印机使用
- 每层楼配置的打印机默认对该楼层员工开放
- 跨楼层使用需联系 IT 添加权限

## 外接显示器无法识别

### 排查步骤
1. 检查连接线是否插紧（HDMI/DP/USB-C）
2. Win+P → 选择"扩展"或"复制"模式
3. 设置 → 显示 → 检测 → 检查是否识别到第二屏
4. 更新显卡驱动：设备管理器 → 显示适配器 → 右键更新驱动
5. 如使用扩展坞，确认扩展坞是否支持视频输出
6. 仍无法识别请提交工单

### 注意事项
- 部分安全策略可能禁止外接显示器（涉密岗位）
- 如果设备管理器中外接显示器显示"策略禁止"，需联系 IT 确认

---

## 摄像头 / 麦克风权限

### Windows 隐私设置
1. 设置 → 隐私和安全性 → 摄像头 → 确认已开启
2. 设置 → 隐私和安全性 → 麦克风 → 确认已开启
3. 确认对应的应用（如 Zoom、Teams）已获得权限

### 安全软件拦截
- 部分安全软件会拦截摄像头使用
- 如视频会议需要但被拦截：联系 IT 添加白名单
